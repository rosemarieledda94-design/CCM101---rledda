
# Laboratory 05 - Cloud Data Engineer

## Mission Overview

This laboratory activity focuses on cloud object storage. MinIO was deployed using Docker to create an S3-compatible object storage server. A bucket was created and a sample file was uploaded to demonstrate cloud storage.

## Objectives

* Differentiate Block, File, and Object Storage.
* Deploy MinIO using Docker.
* Access a cloud service through port forwarding.
* Create a storage bucket.
* Upload an object to the cloud.
* Document cloud storage operations using Markdown.

## Tools Used

* KillerCoda Playground
* Ubuntu
* Docker
* MinIO
* GitHub
* Web Browser

## Skills Learned

* Using Docker to deploy a cloud service
* Working with object storage
* Creating and managing buckets
* Uploading objects
* Using Linux command-line commands
* Documenting cloud configurations using Markdown
