## 1. Which cloud infrastructure component do you think is the most important? Why?

For me, the most important cloud infrastructure component is the compute resource because it provides the processing power needed to run applications and services. Without enough computing resources, applications may not work properly or may become slow. Compute resources allow cloud servers to perform different tasks and handle workloads.

## 2. How does Linux support cloud computing?

Linux supports cloud computing by providing a stable operating system environment for running applications and managing server resources. It also provides many useful commands and tools that allow cloud engineers to inspect and manage servers. In this laboratory, Linux allowed me to investigate the resources available in the KillerCoda cloud environment.

## 3. Why is technical documentation important before deploying infrastructure?

Technical documentation is important because it helps engineers understand what resources are available and how the infrastructure is designed. It also makes it easier to plan, troubleshoot, maintain, and explain the system. Proper documentation can help prevent mistakes before a system is deployed.
